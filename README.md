# CodeAlpha Calculator

A modern, fully responsive, and robust calculator web application built with HTML5, CSS3, and Vanilla JavaScript for the CodeAlpha Frontend Development Internship.

## 🚀 Features

- **Arithmetic Operations:** Supports addition, subtraction, multiplication, and division with floating-point precision handling.
- **Advanced Functions:** Includes decimal input, all-clear (AC), backspace deletion (DEL), sign toggling (+/-), and percentage calculation (%).
- **Keyboard Accessibility:** Full keyboard support (number keys, operators, `Enter` / `=` to calculate, `Backspace` to delete, and `Escape` to clear).
- **Safe Error Handling:** Gracefully handles edge cases such as division by zero without crashing, displaying clear error messages.
- **Separation of Concerns:** Clean architecture separating core calculation logic from UI event handlers and state management.
- **Responsive Design:** Fluid layout with interactive hover states, focus indicators, and mobile-friendly styling.

## 🛠️ Technologies Used

- **HTML5:** Semantic elements and ARIA accessibility attributes.
- **CSS3:** CSS Grid, Custom Properties (Variables), Flexbox, and transitions.
- **Vanilla JavaScript (ES6+):** Object-oriented classes, state management, and event listeners.
